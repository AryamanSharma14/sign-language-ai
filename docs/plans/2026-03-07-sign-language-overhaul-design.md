# Sign Language AI — Overhaul Design
Date: 2026-03-07

## Overview

Expand the existing sign language gesture recognition MVP with four goals:
1. Restructure the codebase for maintainability
2. Add 6 new gestures (3 ASL letters + 3 phrases)
3. Improve classification accuracy
4. Add a Flask-based web dashboard (live feed + stats)

---

## 1. File Structure

```

│   ├── gestures.py          # Single source of truth: labels, command map, GPIO pins

│   └── utils.py             # Landmark extraction + normalization + palm orientation
│
├── training/
│   ├── collect_data.py      # Webcam → CSV data collection

├── hardware/
│   ├── gpio_controller.py   # Standalone GPIO controller (Pi hardware)

├── inference/

│   └── edge_inference.py    # Pi mode: headless, frame-skip, metrics
│
├── web/
│   ├── app.py               # Flask app: routes + WebSocket (flask-sock)
│   ├── stream.py            # MJPEG frame generator thread

│   └── templates/

│
├── dataset/
│   └── gestures.csv
├── models/
│   └── model.pkl
├── config.py                # All tunables: paths, thresholds, FPS, pins, augment params
├── requirements.txt         # Adds flask, flask-sock
├── requirements_pi.txt
├── install_pi.sh
└── README.md
```

### Key principle
`config.py` is the single place to change any tunable. No magic numbers scattered across files.
`core/gestures.py` is the single source of truth for gesture labels — all other files import from it.

## 3. Accuracy Improvements

### 3a. Palm orientation feature
Add a palm-normal vector to each sample: cross product of (wrist→index_mcp) and (wrist→pinky_mcp).
Feature dimension: 63 (existing) + 3 (palm normal) = 66.

### 3b. Training data augmentation
Applied during training (not stored):
- **Mirror:** flip x-coords of each sample (simulates left hand)
- **Jitter:** add Gaussian noise (sigma=0.01) × 2 copies per sample
Effective dataset size: ~4x without extra collection.

### 3c. Hyperparameter tuning
Replace hardcoded SVC params with `GridSearchCV`:
- Search space: C in [1, 10, 100], gamma in ['scale', 'auto', 0.01, 0.001]
- 5-fold stratified cross-validation
- Best params saved in model.pkl alongside the model

### 3d. Confidence smoothing
Replace simple buffer with Exponential Weighted Moving Average (EWMA):
- Alpha (α) = 0.3 — configurable in config.py
- Recent frames weighted more, older frames decay naturally
- Only emit a gesture event when smoothed confidence >= threshold (default 0.60)

## 4. Web Dashboard

### Backend (web/app.py + web/stream.py)
- Flask serves the HTML at `/`
- MJPEG stream at `/video_feed` — frames generated by a background thread in `stream.py`
  - MediaPipe landmark overlay drawn server-side on each frame
- `flask-sock` WebSocket at `/ws` — pushes JSON gesture events to the browser
  - Event shape: `{ gesture, confidence, command, fps, inference_ms, timestamp }`
- Video and data channels are independent — stats update even under frame lag

### Frontend (web/templates/index.html + static/)
Two-panel layout:

**Left panel — Live feed**
- `<img>` tag pointed at `/video_feed` (MJPEG)
- No JS needed for the video itself

**Right panel — Stats**
- Current gesture label (large) + command translation
- Confidence gauge (CSS progress bar, color-coded: green >=0.8, yellow >=0.6, red <0.6)
- Rolling FPS + inference-ms line chart (Chart.js, 60-point window)
- Gesture history log: scrollable table of last 50 detections (timestamp, gesture, confidence)

### Dependencies added
- `flask`
- `flask-sock`

## 5. Data Flow

```
Webcam
  └── MediaPipe (landmark detection)
        └── core/predictor.py (normalize → EWMA → SVC predict)
              ├── web/stream.py  → MJPEG frames → browser <img>
              ├── web/app.py     → WebSocket JSON → browser JS → Chart.js / history log
              └── hardware/      → GPIO / serial (Pi/Arduino)
```

---

## 6. Out of Scope

- Multi-hand support (single dominant hand only)
- Custom neural network model (SVC is sufficient for 11 gestures)
- User authentication on the web dashboard
- Mobile-responsive layout (desktop only)
